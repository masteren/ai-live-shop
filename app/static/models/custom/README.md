## 条件
- **商用に使わない。**
- **再配布しない。** モデルのファイル(`host.vrm`)はこのリポジトリに含めていない(`.gitignore`)。手元の Mac に置き、サーバへは `deploy/deploy.sh` が送る。
- モデルの作者情報(VRM のメタ情報)を書き換えない。
- 画面に作者のクレジットを表示する。

モデルを使いたい場合は、配布元(模之屋)から入手し、規約と作者の意向を確認すること。
