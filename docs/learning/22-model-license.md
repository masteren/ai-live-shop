# 学习笔记 22:换 3D 模型——素材的许可要看「谁、在哪里、写了什么」

## 做了什么
- 公开版的主播模型换成模之屋的「DeepSeek蓝色大肥鱼」(作者 喜欢看雨OvO)。
- (2026-11-25 更新:作者同意非商用使用后,模型已放进 Git,条件见 `app/static/models/custom/README.md`。下面是当时的做法)
- 模型文件**不进 Git**:放在 `app/static/models/custom/host.vrm`(`.gitignore` 已排除),`deploy.sh` 单独用 scp 传到服务器 `/opt/ai-live-commerce/models/`,compose 以只读方式挂进容器。
- `vrm.js` 按顺序尝试 `custom/host.vrm` → `hana.vrm`(pixiv 示例)。别人 clone 仓库时没有大肥鱼,也能正常显示。
- 模型里 sad / relaxed / surprised 三个表情是空的,用模型自带的形状(困る / にこり / びっくり)补上,所以「困扰」「害羞」现在脸会变。
- 立绘(网页加载中显示的、iOS 用的)从新模型重新导出。页面底部和 README 写明作者和出处。

## 判断许可的过程(这次走了不少弯路)
| 看到的东西 | 能说明什么 | 不能说明什么 |
|---|---|---|
| 模型文件里的元数据(OnlyAuthor / 禁止再发布) | 作者导出时的设置 | 作者在配布页可能另有说明 |
| B 站评论「可以拿去做桌宠」 | 作者同意个人使用 | 回答的是别人、用途是桌宠 |
| 「开源桌宠」项目(MIT) | **代码**是 MIT | 仓库自己写了:模型保留原许可 |
| **模之屋配布页的说明** | 作者写给所有下载者的条件:可改、禁止二次配布、商用需同意 | — |

结论:**以作者在配布页写的条件为准**。「开源」「大家都在用」「已经上传了」都不等于可以再发布。

## 为什么不能放进 GitHub
公开仓库 = 任何人都能下载这个文件 = 二次配布。网页加载模型时浏览器也能拿到文件,这是灰色地带(一般视为「使用」),所以至少做到:不提供下载链接、不进仓库、写明作者。
